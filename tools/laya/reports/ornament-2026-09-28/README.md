# Laya 장면 연출 선택 실험 (2026-09-28)

## 결론

현재 Laya 체크포인트로 `anticipation`(긴장), `relief`(안도), `triumph`(승리), `setback`(타격)을 직접 선택하는 방식은 채택하지 않는다. 48개 합성 문장에서 Laya의 양방향 평균 정확도는 24/48(50.0%)로 게임 표현에 맞춘 키워드 규칙의 30/48(62.5%)보다 낮았다. 특히 안도는 1/12만 맞혔다.

## 방법

- 모델: `aac6fef/laya-multilingual-coreml-ane`; GitHub Actions `macos-15`에서 `compute_units="cpu"`로 실행.
- 독립적으로 정한 상황 24개(분류별 6개)를 게임식 문장과 동의어 재표현으로 각각 작성해 총 48문장을 평가.
- Laya에 동일한 네 선택지를 정방향과 역방향으로 물어 각 확률을 평균한 뒤 최대값을 답으로 선택.
- 기준선은 데모 게임에서 쓰는 흔한 표현에 대한 고정 키워드 규칙. 이 기준선은 재표현을 위한 범용 규칙이 아니다.
- 평가 스크립트: `tools/laya/ornament.py`; 문장별 확률과 판정: `ornament-report.json`.

| 문장 | 개수 | Laya 양방향 | Laya 단방향 | 키워드 규칙 | 선택지 순서에 따른 답 변경 |
|---|---:|---:|---:|---:|---:|
| 게임식 | 24 | 13/24 (54.2%) | 14/24 (58.3%) | 24/24 (100%) | 7/24 (29.2%) |
| 재표현 | 24 | 11/24 (45.8%) | 12/24 (50.0%) | 6/24 (25.0%) | 6/24 (25.0%) |
| 전체 | 48 | 24/48 (50.0%) | 26/48 (54.2%) | 30/48 (62.5%) | 13/48 (27.1%) |

같은 상황의 두 표현에 대해 Laya 답이 일치한 것은 12/24쌍(50.0%)이다.

| 정답 | Laya 정답 수 |
|---|---:|
| 긴장 | 5/12 |
| 안도 | 1/12 |
| 승리 | 10/12 |
| 타격 | 8/12 |

Laya는 안도 문장 12개 중 6개를 승리, 5개를 타격으로 분류했다. 타격 문장 12개 중 3개를 승리로 분류했다. `enemy arrow misses player`를 타격으로, `enemy slash attack hits player`를 승리로 판단한 사례가 있다. 승리는 10/12개를 찾아냈으나, 승리라고 판단한 21개 중 실제 승리는 10개였다.

## 해석과 범위

재표현 집합에서는 Laya가 단순 게임식 키워드 규칙보다 5개 더 맞혔다. 그러나 정확도가 11/24이고 같은 사건의 표현만 달라져도 절반에서 답이 바뀐다. 연출의 정서 방향을 결정하는 데 필요한 안정성이 부족하다. 선택지 순서를 뒤집으면 13/48개가 달라졌고, 양방향 평균은 단방향보다 2개 적게 맞혔다.

표본은 소규모의 영어 합성 문장이다. 실제 게임 문장 분포와 iPhone의 제한된 토큰 어휘를 검증하지 않았다. 이 결과는 이 네 가지 연출 질문에 대한 진단이며 Laya의 모든 판단 능력을 평가한 것은 아니다. 게임의 구조화된 이벤트 값으로 연출을 정하고 Laya는 별도의 좁은 질문을 검증할 때만 고려한다.
