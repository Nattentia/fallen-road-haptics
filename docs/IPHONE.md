# 아이폰에서 실행하기 (Mac 없이)

이 앱은 게임을 아이폰 안에서 실행하면서 Core Haptics로 진동을 낸다. 앱 빌드는 GitHub Actions가 한다. Windows PC에서는 Sideloadly로 설치만 하면 된다.

- 필요 조건: iPhone(iOS 18 이상), Windows PC, USB 케이블, Apple ID
- 설치 파일: [FallenRoadHaptics.ipa (최신 빌드)](https://github.com/Nattentia/fallen-road-haptics/releases/download/ios-latest/FallenRoadHaptics.ipa)

## 처음 한 번만

1. **PC에 Sideloadly 설치**: <https://sideloadly.io>
   - Sideloadly가 iTunes와 iCloud를 요구하면 Apple 웹사이트의 **웹 설치판**을 설치한다. Microsoft Store판은 쓰지 않는다.
2. **아이폰을 USB로 PC에 연결**한다. 아이폰에 "이 컴퓨터를 신뢰하겠습니까?"가 뜨면 신뢰를 누른다.
3. **아이폰 개발자 모드 켜기**: 설정 → 개인정보 보호 및 보안 → 개발자 모드 → 켬 → 재시동.
   - 이 메뉴는 4번 설치를 한 번 시도한 뒤에 나타날 수 있다.

## 설치 (7일마다 반복)

4. 위 링크에서 IPA를 PC로 내려받는다.
5. Sideloadly를 열고 IPA 파일을 창에 끌어 놓는다. Apple ID를 입력하고 **Start**를 누른다. 2단계 인증 코드를 요청하면 입력한다.
   - **보안:** Apple ID 암호는 제3자 앱인 Sideloadly에 입력하게 된다. 불안하면 이 용도로 **별도 Apple ID**를 만들어 쓴다.
6. 아이폰에서 설정 → 일반 → VPN 및 기기 관리 → 해당 Apple ID → **신뢰**.
7. 홈 화면의 **FR Haptics**를 실행한다.

무료 Apple ID로 서명한 앱은 7일 뒤 열리지 않는다. 그때 5번만 다시 하면 된다. 게임 기록은 유지된다.

## 기본 진동 확인

게임에는 행동마다 **똑같은 평범한 진동**(짧은 "윙" 한 번)이 들어 있다. 일반 모바일 게임이 내는 수준의 진동이며, 나중에 햅틱 업스케일러가 이 위에 아이폰 전용 진동을 덧입힌다.

| 행동 | 진동 |
|---|---|
| 내가 공격을 맞음 (막지 못했을 때만) | 기본 진동 |
| 적을 때림 (강공격, 버스트 연속 타격 포함) | 기본 진동 |
| 적을 쓰러뜨림 | 기본 진동 |
| 보스(문지기, 몰락한 왕)를 쓰러뜨림 | 기본 진동 |

- 네 가지 모두 세기·길이·느낌이 같다. 어떤 행동인지는 진동으로 구분되지 않는 것이 정상이다.
- 적을 때린 순간 적이 쓰러지면, 진동 두 개가 겹치지 않고 한 번만 난다.
- 칼날이 적에 닿아 있는 동안에는 진동이 나지 않는다. 이 정보는 기록만 해 두고, 나중에 업스케일러가 쓴다.

확인 방법:
- 가로로 들고, 벨소리 스위치의 **무음 모드를 해제**한다.
- **WALK THE ROAD**를 눌러 적과 싸우면서 위 네 가지 순간에 진동이 나는지 본다.
- 오른쪽 위 패널:

| 줄 | 의미 |
|---|---|
| `touch→native` | 손가락 입력부터 앱(Swift)이 칼날 접촉 신호를 받기까지(ms) |
| `bridge JS→Sw` | 게임(JS)에서 앱(Swift)까지 전달 시간 |
| `event→base` | 게임에서 행동이 일어난 뒤 기본 진동 명령까지(ms) |
| `sync rtt` | 두 시계를 맞출 때의 왕복 시간 |

- **햅틱** 버튼: 진동 켜기/끄기.
- **기록 저장** 버튼: 전체 로그를 CSV로 저장한다. "파일에 저장"을 고른다.

## 2단계 확인: Laya 실기기 실행

- **Lab** 버튼 → **fp16 · ANE** → 1~3분 기다린다.
- 표시되는 항목: 로드 시간, 메모리, 질문 1개 / 결정 세트 1·3·4개의 지연(p50/p95), 원본 대비 확률 오차, 판정.
  - 판정 기준: 3질문 p95 ≤ 100ms이면 스와이프 도중 응답 가능.
- 비교할 때는 **w8 · ANE**(8비트 압축)와 **fp16 · CPU+GPU**도 실행한다.
- **결과 저장**으로 파일에 저장한다.

## 결과 공유 시 주의

저장한 CSV와 결과 파일에는 기기 모델과 iOS 버전이 들어갈 수 있다. 공개 저장소나 이슈에 올리지 않는다. 수치만 옮겨 적는다.
