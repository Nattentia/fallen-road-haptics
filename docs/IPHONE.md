# 아이폰에서 실행하기 (Mac 없이)

이 앱은 게임을 아이폰 안에서 실행하면서 Core Haptics로 진동을 낸다. 앱 빌드는 GitHub Actions가 한다. Windows PC에서는 Sideloadly로 설치만 하면 된다.

- 필요 조건: iPhone(iOS 18 이상), Windows PC, USB 케이블, Apple ID
- 설치 파일: [FallenRoadHaptics.ipa (최신 빌드)](https://github.com/Nattentia/fallen-road-haptics/releases/download/ios-latest/FallenRoadHaptics.ipa)

## 처음 한 번만

1. **PC에 Sideloadly 설치**: <https://sideloadly.io>
   - Sideloadly가 iTunes와 iCloud를 요구하면 Apple 웹사이트의 **웹 설치판**을 설치한다. Microsoft Store판은 쓰지 않는다.
2. **아이폰을 USB로 PC에 연결**한다. 아이폰에 "이 컴퓨터를 신뢰하겠습니까?"가 뜨면 신뢰를 누른다.
3. **아이폰 개발자 모드 켜기**: 설정 → 개인정보 보호 및 보안 → 개발자 모드 → 켬 → 재시동.
   - 이 메뉴는 4번 설치를 한 번 시도한 뒤에 나타날 수 있다.

## 설치 (7일마다 반복)

4. 위 링크에서 IPA를 PC로 내려받는다.
5. Sideloadly를 열고 IPA 파일을 창에 끌어 놓는다. Apple ID를 입력하고 **Start**를 누른다. 2단계 인증 코드를 요청하면 입력한다.
   - **보안:** Apple ID 암호는 제3자 앱인 Sideloadly에 입력하게 된다. 불안하면 이 용도로 **별도 Apple ID**를 만들어 쓴다.
6. 아이폰에서 설정 → 일반 → VPN 및 기기 관리 → 해당 Apple ID → **신뢰**.
7. 홈 화면의 **FR Haptics**를 실행한다.

무료 Apple ID로 서명한 앱은 7일 뒤 열리지 않는다. 그때 5번만 다시 하면 된다. 게임 기록은 유지된다.

## 진동 확인

게임의 모든 행동에는 **똑같은 평범한 진동**(짧은 "윙" 한 번)이 기본으로 들어 있다. 일반 모바일 게임이 내는 수준의 진동이다. 햅틱 업스케일러는 이 위에 아이폰 전용 진동을 덧입힌다.

| 구분 | 행동 |
|---|---|
| 내가 받는 것 | 공격을 그대로 맞음 · 방패로 막음 · 방패가 부서짐 · 쓰러짐(패배) |
| 내가 하는 것 | 적을 때림(강공격, 버스트 연속 타격 포함) · 버스트 발동 |
| 공격이 막힘 | 적이 막음 · 적이 받아쳐 흘림(PARRIED) |
| 좋은 순간 | 완벽 막기·완벽 회피 반격 · 적의 방어가 무너짐 · 적 처치 · 보스(문지기, 몰락한 왕) 처치 |

- **햅틱** 버튼을 누를 때마다 진동 방식이 바뀐다: **기본+업스케일** → **기본만** → **끔**. 같은 장면을 "기본만"과 "기본+업스케일"로 번갈아 느껴 보면 추가 층이 무엇을 더하는지 알 수 있다.
- 두 행동이 한순간에 겹치면(예: 때린 순간 적이 쓰러짐) 기본 진동은 한 번만 난다.
- 휘두르기, 회피 시작, 적의 공격 예고, 메뉴 버튼에는 기본 진동이 없다.

확인 방법:
- 가로로 들고, 벨소리 스위치의 **무음 모드를 해제**한다.
- **WALK THE ROAD**를 눌러 적과 싸운다.
- 오른쪽 위 패널:

| 줄 | 의미 |
|---|---|
| `touch→native` | 손가락 입력부터 앱(Swift)이 칼날 접촉 신호를 받기까지(ms) |
| `bridge JS→Sw` | 게임(JS)에서 앱(Swift)까지 전달 시간 |
| `cmd→native` | 업스케일러 명령을 보낸 뒤 앱이 진동 장치에 넘기기까지(ms) |
| `sync rtt` | 두 시계를 맞출 때의 왕복 시간 |

- **기록 저장** 버튼: 지연 로그(CSV)와 업스케일러 기록(jsonl, 게임이 보낸 신호와 진동 명령 전체)을 함께 저장한다. "파일에 저장"을 고른다.

## 업스케일 Lab (S1, S2)

**업스케일 Lab** 버튼을 누르면 게임 화면이 시험 화면으로 바뀐다. 위쪽 버튼으로 S1과 S2를 고른다. 끝나면 **게임으로**를 누른다.

진행 순서:
1. 무음 모드를 해제하고, 조용한 곳에서 폰을 평소처럼 두 손으로 가로로 잡는다.
2. **S1**에서 먼저 **자동 측정**을 누른다. "측정 완료"가 뜰 때까지 기다린다(몇 초). 이때 진동은 거의 느껴지지 않는 것이 정상이다.
3. 각 시험에는 A, B, C… 줄이 있다. 줄마다 **재생**을 눌러 진동을 느끼고, 같은 줄에서 가장 가까운 답을 누른다. 여러 번 재생해도 된다. A, B, C가 무엇인지는 일부러 숨겨 두었다. 순서도 매번 섞인다.
4. 모든 줄에 답했으면 맨 아래 **결과 저장**을 누르고 "파일에 저장"을 고른다.
5. 위쪽에서 **S2**를 눌러 같은 방식으로 진행하고, 다시 **결과 저장**을 누른다.
6. 저장한 두 파일(`lab-s1-….json`, `lab-s2-….json`)을 보내 준다.

시험 내용:
- **S1**: 재생 장치 확인. 기본 진동, 톡톡 입자의 간격, 진동을 도중에 바꿀 때의 이음새, 실시간 세기 조절, 긴 진동의 이음새, 기본 진동과 추가 층을 동시에 낼 때, 진동을 끝낼 때.
- **S2**: 부품과 세기 균형. 부품 6종을 기본 진동 위에 얹었을 때, 부품을 여러 개 겹쳤을 때, 작은·중간·큰 타격의 전체 세기, 크기 순서.

## 2단계 확인: Laya 실기기 실행

- **Lab** 버튼 → **fp16 · ANE** → 1~3분 기다린다.
- 표시되는 항목: 로드 시간, 메모리, 질문 1개 / 결정 세트 1·3·4개의 지연(p50/p95), 원본 대비 확률 오차, 판정.
  - 판정 기준: 3질문 p95 ≤ 100ms이면 스와이프 도중 응답 가능.
- 비교할 때는 **w8 · ANE**(8비트 압축)와 **fp16 · CPU+GPU**도 실행한다.
- **결과 저장**으로 파일에 저장한다.

## 결과 공유 시 주의

저장한 CSV와 결과 파일에는 기기 모델과 iOS 버전이 들어갈 수 있다. 공개 저장소나 이슈에 올리지 않는다. 수치만 옮겨 적는다.
